# Maël Verré — conseil en gestion de patrimoine

Site vitrine réalisé avec React, TypeScript et Vite.

## Développement local

```sh
npm install
npm run dev
```

## Publication sur Vercel

Importer le dépôt GitHub `Lownheur/mael-verre-patrimoine` depuis le tableau de bord Vercel. Vercel détecte Vite automatiquement. Vérifier ces paramètres si nécessaire :

- Framework : Vite
- Commande de build : `npm run build`
- Dossier de sortie : `dist`
- Répertoire racine : `.`

Puis cliquer sur **Deploy**. Les déploiements suivants se feront automatiquement à chaque push sur `main`.

## À compléter avant publication professionnelle

Renseigner les coordonnées et mentions propres au conseiller : identité juridique, statut, numéro ORIAS, rémunération, médiateur et informations de confidentialité. Confirmer les formulations relatives au partenariat Predictis. Le formulaire actuel est une démonstration et n’envoie aucune donnée.
